# 图形学大作业 - 体素沙盒 (Voxel Sandbox) 开发

## 1. 项目背景与总体目标
本项目为《图形学与虚拟现实》课程设计大作业。
*   **核心目标**：利用 Godot 引擎制作一个体素（Voxel）沙盒游戏，通过**自定义网格生成算法**和 **Shader 编程**体现图形学底层知识。
*   **关键约束**：禁止使用 Pygame；必须有图形界面；代码需有详尽注释；需在代码中明确标注“独立设计”的部分。

## 2. 图形学核心考点（必须实现）
为了获得高分，本项目**不能**简单地堆叠 Godot 的 `MeshInstance3D` 节点，必须手动实现以下技术：
1.  **动态网格构建 (Procedural Mesh Generation)**：
    *   使用代码手动定义顶点缓冲（Vertex Buffer）和索引缓冲（Index Buffer）。
    *   实现**面剔除优化 (Face Culling)**：只生成暴露在空气中的方块面，隐藏被遮挡的内部面。
2.  **纹理映射 (Texture Mapping)**：
    *   使用 **Texture Atlas（纹理图集）**，至少包含 2 种以上纹理（如草地、泥土、石头）[cite: 1]。
    *   通过算法动态计算并分配每个面对应的 UV 坐标。
3.  **场景渲染 (Scene Rendering)**：
    *   场景中物体/背景总数不少于 3 个（例如：地形区块、玩家模型、动态粒子或交互方块）[cite: 1]。
4.  **自定义着色器 (Custom Shaders)**：
    *   手写 GLSL/GDShader 实现基础光照（如 Blinn-Phong）或视觉特效。
    *   （加分项）实现类似 Minecraft 的 **草地群系染色 (Biome Grass Tint)**：在 Shader 中对草顶面/草侧面草皮部分进行颜色乘法，并按位置噪声或群系图产生色深变化。

## 3. 具体开发步骤建议

### 第一阶段：体素底层框架
1.  **数据结构**：建立 `Chunk` 类，使用三维数组（如 $16 \times 16 \times 16$）存储 `VoxelType`。
2.  **网格生成算法**：
    *   遍历数组，检查相邻方块。
    *   利用 Godot 的 `SurfaceTool` 或 `ArrayMesh` 手动添加顶点和法线。
    *   

### 第二阶段：渲染与视觉
1.  **UV 算法**：实现一个 `get_uvs(voxel_type, face_side)` 函数，根据图集偏移量计算 UV。
2.  **Shader 开发**：
    *   实现一个包含基础光照模型的材质。
    *   （推荐）实现 “草地群系染色”：
        *   **草顶面**：对 `grass_block_top.png` 进行乘色（tint），模拟不同群系的草色。
        *   **草侧面**：使用 `grass_block_side.png` 作为底图，再用 `grass_block_side_overlay.png` 作为“仅草皮部分”的覆盖层，在 Shader 中对覆盖层乘色并进行 alpha 叠加，使侧面草皮与顶面草色一致。
        *   为了仍然满足 “Texture Atlas + UV 算法” 的要求，可将图集组织为 **多行 Atlas**：第 0 行放基础纹理，第 1 行放覆盖层纹理；Shader 通过对 UV 做行偏移采样覆盖层。
        *   网格侧可用 **顶点色/自定义属性作为掩码** 标记“哪些面需要染色/叠加覆盖层”，以体现图形学底层数据通道的使用（Vertex Attribute → Fragment Shader）。
    *   （可选）添加简单的顶点动画（如方块轻微晃动或边缘高亮）。

### 第三阶段：交互系统
1.  **射线检测 (Raycasting)**：实现玩家准星拾取方块的功能。
2.  **动态更新**：当方块增加/删除时，仅重新生成受影响区块的网格，而非重建整个世界。

## 4. 交付要求清单
1.  **可运行程序**：确保导出后可直接现场演示。
2.  **源代码**：
    *   **逐条代码注释**：特别是涉及数学变换、网格构建的部分。
    *   **独立设计标注**：在核心算法（如面剔除、UV计算）处加上 `# --- INDEPENDENT DESIGN START ---`。
3.  **程序设计报告**：记录算法原理、遇到的问题（如性能瓶颈、坐标转换错误）及解决方法。
